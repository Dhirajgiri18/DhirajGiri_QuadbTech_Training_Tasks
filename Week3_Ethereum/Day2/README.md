# Expense Tracker dApp

A decentralized application (dApp) for tracking expenses using Ethereum smart contracts.

## Features

- Connects to MetaMask
- Adds expenses with category, amount, and description
- Fetches and displays expense history from the blockchain

## Setup

1. Clone the repository:
   ```sh
   git clone https://github.com/your-username/expense-tracker-dapp.git
   cd expense-tracker-dapp
   ```
2. Install dependencies:

```sh
npm install
```

3. Run the project locally:

```sh
npm run dev
```

4. Deployment
   The project is deployed on Vercel:
   https://expense-tracker-dapp-kg2sotn51-dhirajgiri18s-projects.vercel.app/

To redeploy:

```sh
vercel --prod
```
