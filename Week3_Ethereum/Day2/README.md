# Expense Tracker dApp

A decentralized application (dApp) for tracking expenses using Ethereum smart contracts.

## Features

- Connects to MetaMask
- Adds expenses with category, amount, and description
- Fetches and displays expense history from the blockchain

# Gas Fee Tracker dApp

A decentralized application (dApp) for tracking gas fees for transactions on the Ethereum blockchain
## Features

- Connects to MetaMask
- Records and displays gas fees for transactions
- Compares gas fees with previous transactions

Deployment
   The project is deployed on Vercel: https://gas-fee-tracker-c6tf43593-dhirajgiri18s-projects.vercel.app
