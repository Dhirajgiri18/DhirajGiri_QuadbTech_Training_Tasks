# Dhiraj Giri's QuadB Technologies Blockchain Training Repository

Welcome to the **QuadB Technologies Blockchain Training Repository**! This repository contains all the learning materials, tasks, and projects that I have worked on as part of my blockchain training at QuadB Technologies.

## Project Overview

This repository tracks my progress through blockchain training, covering various blockchain technologies and frameworks. It includes topics such as Ethereum, Aptos, Solana, and ICP (Internet Computer Protocol). The goal is to develop practical blockchain development skills, focusing on hands-on projects and smart contract development.


## Repository Structure

The repository is organized as follows:

- **`Week1_ICP/`**: Tasks and projects related to the Internet Computer Protocol (ICP) blockchain.
- **`Week2_Solana/`**: Tasks and projects focused on the Solana blockchain, including NFT creation and token development.
- **`Week3_Ethereum/`**: Ethereum-based tasks, including smart contract development, gas fee optimization, and dApp integration.
- **`Week4_Aptos-Sui/`**: Projects related to Aptos and Sui blockchains, focusing on Move programming language and smart contract development.

  

##Tasks and Projects
This repository contains several tasks and projects focused on different blockchain technologies:

ICP: Working with Internet Computer Protocol (ICP), creating DApps, interacting with the ICP blockchain.


Solana: Smart contract development, Solana token creation, NFT creation, and smart contract interactions on Solana.


Ethereum: Smart contract development using Solidity, deploying to Ethereum, and dApp integration.


Aptos & Sui: Introduction to Aptos and Sui blockchains, developing smart contracts using the Move programming language.


Each project is documented with explanations, source code, and step-by-step guides.
