# Lending-Borrowing-Dapp using Atos move

This project is a Lending & Borrowing dApp built on the Aptos blockchain. It allows users to deposit and borrow funds using smart contracts. The application integrates with the Petra wallet for secure wallet connections and transactions. Key features include:

Wallet Connection: Users can connect their wallet to the dApp.

Deposit Funds: Users can deposit funds into the lending pool.

Borrow Funds: Users can borrow funds from the lending pool.

View Total Lending/Borrowing Amount: Displays the total amounts of funds lent and borrowed by the user.

Repayment and Withdrawal: Enables users to repay loans and withdraw deposited funds.

The dApp features a clean, responsive user interface built with React and Material UI, offering a modern experience across devices.
