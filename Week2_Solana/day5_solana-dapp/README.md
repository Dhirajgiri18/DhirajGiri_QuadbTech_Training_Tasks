# Solana dApp with Phantom Wallet Integration

![Solana Logo](https://solana.com/src/img/branding/solanaLogoMark.svg) ![Phantom Wallet Logo](https://phantom.app/favicon.ico)

A decentralized application that enables SOL transfers and wallet management through Phantom Wallet integration.

## Features

- 🔐 Secure Phantom Wallet authentication
- 💸 Send SOL transactions
- 📊 View wallet balance and transaction history
- 🌐 Supports Devnet/Testnet/Mainnet
- 📱 Mobile-responsive interface

## Prerequisites

- [Node.js](https://nodejs.org/) (v16+)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Phantom Wallet](https://phantom.app/) extension
